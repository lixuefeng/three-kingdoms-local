# Contributing

Use Node 22+, run `npm test`, and keep changes focused. Add meaningful regression tests for rule/interaction changes. Test provider behavior with mocked responses, never embedded credentials or paid calls.

Do not commit runtime data, profiles, match archives, private AI traces, recovery keys, tokens or `.env.local`. Do not add commercial artwork, recordings or copied articles without compatible licensing and attribution. Prefer original vector assets.

Explain before/after behavior, rule version and validation in pull requests. Distinguish published strategy sources, implementation-specific inferences and measured results. Mock tests alone do not establish playing strength.
